What's a build request?

One specific thing changed, added, or automated — a new pipeline stage, a follow-up sequence for expired listings, Zillow leads flowing straight into your CRM, a report showing which lead source actually closes. The kind of work a dev shop bills by the hour for. On plan, it's built into your month.

The ground rules, up front: we scope each request together, requests don't roll over month to month, and bigger items — new API integrations, data migrations, full redesigns — get their own flat quote first. Plans run 12 months; Care is month-to-month, cancel anytime.

Care — the keep-it-running plan
Hosting, database, uptime, unlimited bug fixes, security updates, and support — no build work, no term. A flat monthly by segment, month-to-month, cancel anytime. Included in every On-Plan tier, optional after any Own-It build.
